penjelasan tiap menu di program

1. Lihat Daftar Unit Tersedia
Menampilkan semua kendaraan tambang yang terdaftar kode, nama, tarif harian, kategori, dan detail khusus tiap tipe seperti kapasitas ton/bucket atau tipe blade

2. Sewa Unit Kendaraan
Menampilkan daftar unit lalu memintamu memasukkan kode unit, jumlah hari sewa, dan status member (y/t). Program menghitung total biaya otomatis makin lama sewa, makin besar diskon, ditambah diskon 5% ekstra kalau member — lalu mencatat transaksi ke riwayat.

3. Lihat Riwayat Penyewaan
Menampilkan daftar semua transaksi sewa yang sudah dilakukan selama program berjalan (nama unit, jumlah hari, total biaya). Kosong lagi setiap kali program di-restart

4. Tambah Unit Baru
Memungkinkan menambah kendaraan baru ke daftar pilih jenisnya (Dump Truck/Excavator/Bulldozer), lalu isi kode, nama, tarif, dan data spesifik sesuai jenisnya. Unit baru ini juga hilang saat program di restart karena hanya tersimpan di memory.

5. Keluar
Menghentikan program dan menutup aplikasi
